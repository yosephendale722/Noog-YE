# Noog-Local-Music-Player
![Mocha](Screenshots/Mocha.png)

Noog is a local music player for Android, built with Jetpack Compose and Media3, designed for clean playback, animated canvas-style covers, and a modern listening experience.

⚠ N.B: This repository has not yet been used to upload the app's source code. It is solely for brief introduction and feedback collection.
