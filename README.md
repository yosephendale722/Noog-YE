# Noog-Local-Music-Player
![Mocha](Screenshots/Mocha.png)

Noog is a local music player for Android, built with Jetpack Compose and Media3, designed for clean playback, animated canvas-style covers, and a modern listening experience.

⚠ NB. The app is still Work In Progress) and is far away from a stable release, that's why you might notice a lot of bugs, missing features, and some instability problems, but Don't worry, everything will worked on in the near future.
